# Scoreboard
A lightweight HTML for Friends and Foes
Scoreboard: Spieler mit Farbe anlegen, Spiele, Siege, Winrate, Serie, Ranking mit 🎯 beim Führenden
Neues Spiel: Sieger antippen oder Darts (301/501/701, Double-Out, Best of 1/3/5/7 Legs)
Dart-Screen: Touch-Dartscheibe mit großen Double/Triple, Bull-Buttons, Bust-Erkennung, Dart zurück
Finish-Vorschläge: Route wird angezeigt, Zielfeld pulsiert
Training: Solo-Spiel, zählt nur für die Statistik
Dopamin: Konfetti, Sound, Banner (Sieg, Serie, 180, Leg), Vibration
Statistik: Ø, höchste Runde, 180er, High Finish, bestes Leg, Double-Quote, T20, Trefferbild-Heatmap
Daten: Export/Import als JSON, Rückgängig, Löschen nur per Namenseingabe
Technik: Eine HTML-Datei, läuft offline im Browser, Daten liegen lokal im Gerät
